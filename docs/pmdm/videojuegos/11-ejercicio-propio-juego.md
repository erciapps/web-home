# 12. Ejercicio · Crea tu propio videojuego 2D

## Propuesta

Recrea lo trabajado en clase, pero construyendo **tu propio juego de plataformas 2D**.

No se trata de copiar ERCIGAME cambiando únicamente el personaje. Debes utilizar **otros assets y otro tileset** y diseñar un escenario propio aplicando las mismas técnicas que hemos utilizado en clase.

## Requisitos mínimos

Tu proyecto debe incluir:

- un proyecto **Universal 2D** en Unity 6;
- un conjunto de assets diferente al utilizado en clase;
- un escenario propio construido con **Tilemap**;
- separación entre suelo y elementos decorativos;
- colisiones correctamente configuradas;
- un personaje controlable mediante `Rigidbody2D`;
- movimiento horizontal;
- salto con detección de suelo;
- `GroundCheck` y una layer para el suelo;
- al menos las animaciones **Idle**, **Run** y **Jump**;
- orientación del personaje según la dirección del movimiento;
- al menos un tipo de objeto recogible;
- una meta o condición clara para terminar el nivel.

## Elementos para personalizar el juego

El juego debe tener una identidad propia. Puedes modificar, entre otras cosas:

- temática;
- personaje;
- tileset;
- fondo;
- distribución del nivel;
- objetos recogibles;
- obstáculos;
- objetivo del nivel.

## Siguientes etapas

Cuando los requisitos mínimos funcionen, deberás incorporar mejoras como (se verán en clase):

- contador de monedas o puntuación;
- enemigos;
- pinchos o trampas;
- plataformas móviles;
- puerta y llave;
- checkpoints;
- varias escenas o niveles;
- pantalla de victoria;
- pantalla de Game Over;
- música y efectos de sonido;
- partículas;
- interfaz con vidas o puntuación.

## Entrega

La entrega debe contener:

1. El proyecto de Unity funcionando.
2. Pequeño vídeo donde se vea el nivel en funcionamiento.
3. Un breve `README.md` con:
   - nombre del juego;
   - objetivo;
   - controles;
   - assets utilizados y su procedencia;
   - mejoras añadidas respecto al ejemplo de clase.
