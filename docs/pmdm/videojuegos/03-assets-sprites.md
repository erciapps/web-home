# 3. Assets y sprites

Los **assets** son los recursos que utiliza el juego: imágenes, sonidos, animaciones, fuentes, scripts, etc.

Para un juego 2D normalmente necesitaremos como mínimo:

- fondo;
- tiles o elementos del escenario;
- personaje;
- objetos que se puedan recoger;
- obstáculos;
- interfaz y sonidos.

## Importar una imagen

Arrastra el archivo PNG a la ventana **Project** de Unity. Después selecciónalo para configurar sus propiedades en el **Inspector**.

!!! tip "Spritesheets"
    Si una imagen contiene varios fotogramas del personaje, configura `Sprite Mode` como **Multiple** y utiliza el **Sprite Editor** para separarlos.
