# 1. Crear el primer proyecto

## Objetivo

Crear un proyecto 2D en Unity Hub y comprobar que abre correctamente en el editor.

1. Abre **Unity Hub**.
2. Pulsa **New project**.
3. Selecciona una plantilla **2D**.
4. Pon un nombre al proyecto.
5. Elige la carpeta donde se guardará.
6. Pulsa **Create project**.

!!! note
    Todo lo que añadamos a partir de aquí quedará dentro de la carpeta del proyecto de Unity.
