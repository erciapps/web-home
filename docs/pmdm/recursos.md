# Recursos de PMDM

Esta página queda preparada como índice de recursos del módulo.

## Unity

- Unity Hub y Unity 6.
- Documentación oficial de Unity.
- Assets 2D y spritesheets.
- Repositorio de ejemplos de clase.

## Organización recomendada

```text
Assets/
├── Art/
├── Audio/
├── Prefabs/
├── Scenes/
└── Scripts/
```

!!! tip
    Puedes ir añadiendo enlaces, archivos y ejercicios aquí sin tocar la configuración general de la web.
