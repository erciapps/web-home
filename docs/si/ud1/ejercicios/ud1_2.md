# UD1.2 · Creación de directorios con Bash

En este ejercicio vas a crear una estructura de directorios mediante un **script Bash**. Practicarás `mkdir`, rutas, variables, confirmación de usuario, `tree` y redirección de la salida a un fichero.

!!! info "Entorno de trabajo"
    Trabaja desde el **terminal integrado de VS Code**. Todo el ejercicio debe permanecer dentro de `/workspace/ud1`.

## Preparación

Crea el script principal directamente en la carpeta de la unidad:

```text
/workspace/ud1/ud1_2.sh
```

La estructura generada por el script debe quedar en:

```text
/workspace/ud1/pruebas/ud1_2/
```

Al comenzar, tu zona de trabajo debe quedar aproximadamente así:

```text
/workspace/ud1/
├── ud1_2.sh
├── scripts/
└── pruebas/
```

## Estructura que debe generar el script

Al ejecutar `ud1_2.sh` debes obtener:

```text
/workspace/ud1/pruebas/ud1_2/
└── APLI/
    ├── WORD/
    │   ├── TEXTO/
    │   └── NOTAS/
    ├── ACCESS/
    ├── EXCEL/
    │   ├── TABLAS/
    │   └── INFO/
    ├── PROG/
    │   ├── JAVA/
    │   └── PYTHON/
    └── VARIOS/
        └── CSHARP/
```

## Condiciones

Tu script debe cumplir **todas** estas condiciones:

1. Debe poder ejecutarse **desde cualquier ruta**. No debes depender del directorio actual desde el que se lance.
2. Antes de crear la estructura debe **preguntar al usuario** si desea continuar.
3. Si el usuario acepta, debe crear toda la estructura dentro de `/workspace/ud1/pruebas/ud1_2`.
4. Al finalizar debe mostrar un mensaje indicando que la tarea se ha realizado correctamente.
5. Debe mostrar en pantalla el árbol creado utilizando `tree`.
6. La salida de `tree` debe guardarse también en:

```text
/workspace/ud1/pruebas/ud1_2R.txt
```

!!! warning "Importante"
    No crees los directorios manualmente. La estructura completa debe ser generada por `ud1_2.sh`.

## Comprobación

Prueba primero desde `/workspace`:

```bash
cd /workspace
bash /workspace/ud1/ud1_2.sh
```

Después ejecútalo desde otra ubicación, por ejemplo:

```bash
cd /tmp
bash /workspace/ud1/ud1_2.sh
```

En ambos casos el resultado debe generarse exactamente en la misma ubicación.

Comprueba finalmente:

```bash
tree /workspace/ud1/pruebas/ud1_2
cat /workspace/ud1/pruebas/ud1_2R.txt
```
