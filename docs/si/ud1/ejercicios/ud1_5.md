# UD1.5 · Edición de ficheros con `sed`

En este ejercicio vas a trabajar con un fichero de texto desde un script Bash. El objetivo es consultar, editar y borrar líneas utilizando `sed`.

!!! info "Entorno de trabajo"
    Trabaja desde el **terminal integrado de VS Code** y mantén todos los archivos del ejercicio dentro de `/workspace/ud1`.

## Preparación

Crea el script:

```text
/workspace/ud1/ud1_5.sh
```

Crea también la zona de pruebas:

```text
/workspace/ud1/pruebas/ud1_5/
```

Dentro de ella crea un archivo llamado `lista.txt` con una lista de elementos, uno por línea. Puedes utilizar colores, ciudades, lenguajes de programación, videojuegos, componentes informáticos o cualquier otra lista similar.

Por ejemplo:

```text
Rojo
Amarillo
Naranja
Azul
Blanco roto
Rosa palo
```

El fichero debe contener suficientes elementos para poder realizar varias pruebas durante el desarrollo del script.

## Enunciado

El script debe permanecer en ejecución hasta que el usuario decida salir.

### 1. Mostrar la lista

Muestra el contenido de `lista.txt` numerando sus líneas. La numeración debe obtenerse a partir del propio fichero, no escribirse manualmente.

El resultado será similar a:

```text
1. Rojo
2. Amarillo
3. Naranja
4. Azul
5. Blanco roto
6. Rosa palo
```

### 2. Seleccionar un elemento

Pide al usuario que introduzca el número de uno de los elementos de la lista.

Si el número no corresponde con ninguna línea existente, muestra un aviso y vuelve a solicitarlo.

Cuando el número sea correcto:

1. Limpia la pantalla.
2. Muestra el contenido de la línea seleccionada.
3. Muestra las siguientes opciones:

```text
[e] Editar
[b] Borrar
[c] Cancelar
```

### 3. Editar

Si el usuario selecciona `e`, pide el nuevo contenido de la línea y sustituye el valor anterior.

Después de realizar el cambio, muestra de nuevo la lista actualizada.

### 4. Borrar

Si el usuario selecciona `b`, pregunta si realmente desea eliminar el elemento seleccionado:

```text
¿Deseas borrar este elemento? [s/n]:
```

Si responde `s`, elimina la línea y muestra la lista resultante.

Si responde `n`, no realices ningún cambio y vuelve a mostrar la lista inicial.

Después de cualquiera de las dos opciones, el programa debe continuar funcionando y permitir seleccionar otro elemento.

### 5. Cancelar

Si el usuario selecciona `c`, no debe modificarse el fichero. El programa volverá a mostrar la lista y permitirá realizar una nueva selección.

## Condiciones

- Utiliza `sed` para consultar y modificar las líneas del fichero.
- El número de elementos debe obtenerse a partir del contenido real de `lista.txt`.
- No supongas en el código que la lista tiene siempre el mismo número de líneas.
- Debes comprobar que el número introducido corresponde con una línea existente.
- El script debe permitir editar o borrar varios elementos sin tener que ejecutarlo de nuevo.
- Los cambios realizados deben conservarse en `lista.txt`.
- Todos los archivos utilizados por el ejercicio deben permanecer dentro de `/workspace/ud1`.

## Comprobación

Antes de terminar, comprueba al menos estos casos:

- seleccionar la primera línea;
- seleccionar la última línea;
- introducir un número que no existe;
- editar un elemento y comprobar que el cambio queda guardado;
- borrar un elemento y comprobar que la numeración se adapta a la nueva lista;
- cancelar una operación y comprobar que el fichero no cambia.
