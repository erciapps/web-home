# UD1.7 · Generación de estructuras desde un fichero de instrucciones

En este ejercicio vas a crear un script Bash capaz de **leer instrucciones desde un fichero de texto** y ejecutarlas para generar automáticamente una estructura de directorios y archivos.

El fichero no contendrá comandos Bash completos. Cada línea indicará una operación y una ruta separadas por `;`. El script deberá interpretar esos datos y decidir qué comando ejecutar.

!!! info "Entorno de trabajo"
    Trabaja desde el **terminal integrado de VS Code** y mantén todos los archivos del ejercicio dentro de `/workspace/ud1`.

## 1. Archivos del ejercicio

Crea el script principal:

```text
/workspace/ud1/ud1_7.sh
```

Crea también el fichero de instrucciones:

```text
/workspace/ud1/BashFile.txt
```

El script deberá generar su estructura dentro de:

```text
/workspace/ud1/pruebas/ud1_7/
```

No crees manualmente la estructura final. Debe ser generada por `ud1_7.sh` a partir del contenido de `BashFile.txt`.

## 2. Estructura que debe generarse

Al finalizar la ejecución, debe existir:

```text
/workspace/ud1/pruebas/ud1_7/
├── scripts/
│   ├── copia.sh
│   └── usuarios.sh
├── datos/
│   ├── usuarios.txt
│   └── equipos.txt
├── backups/
│   ├── diarios/
│   └── semanales/
└── logs/
    └── sistema.log
```

## 3. Fichero `BashFile.txt`

Copia exactamente estas instrucciones:

```text
MKDIR;./pruebas/ud1_7/scripts
TOUCH;./pruebas/ud1_7/scripts/copia.sh
TOUCH;./pruebas/ud1_7/scripts/usuarios.sh
MKDIR;./pruebas/ud1_7/datos
TOUCH;./pruebas/ud1_7/datos/usuarios.txt
TOUCH;./pruebas/ud1_7/datos/equipos.txt
MKDIR;./pruebas/ud1_7/backups/diarios
MKDIR;./pruebas/ud1_7/backups/semanales
MKDIR;./pruebas/ud1_7/logs
TOUCH;./pruebas/ud1_7/logs/sistema.log
```

Cada línea tiene dos campos:

```text
INSTRUCCION;RUTA
```

Por ejemplo:

```text
MKDIR;./pruebas/ud1_7/scripts
```

representa:

```text
Instrucción: MKDIR
Ruta:        ./pruebas/ud1_7/scripts
```

Las únicas instrucciones válidas en este ejercicio son:

| Instrucción | Acción |
|---|---|
| `MKDIR` | Crear un directorio mediante `mkdir -p`. |
| `TOUCH` | Crear un fichero vacío mediante `touch`. |

!!! note "Orden de las instrucciones"
    El fichero se procesa de arriba hacia abajo. Por tanto, un directorio debe existir antes de intentar crear dentro de él un fichero con `touch`.

## 4. Preparar la ruta de trabajo

El script puede ejecutarse desde cualquier directorio. Al comenzar, obtén la ubicación en la que se encuentra el propio script y desplázate hasta ella.

Debes utilizar la variable `BASE`:

```bash
BASE="$(dirname "$0")"
```

Después de obtener `BASE`, debes hacer `cd "$BASE"` para que las rutas relativas que aparecen en `BashFile.txt` se interpreten desde `/workspace/ud1`.

## 5. Obtener el número de instrucciones

Calcula cuántas líneas contiene `BashFile.txt` utilizando `wc -l` y guarda el resultado en una variable llamada:

```text
totalLineas
```

No escribas directamente en el script el número de instrucciones del fichero.

## Antes de programar · Separar campos con `IFS` y un array

Hasta ahora hemos obtenido líneas utilizando `sed`. En este ejercicio, cada línea contiene dos datos separados por `;`.

```text
MKDIR;./pruebas/ud1_7/scripts
```

Utilizaremos esta instrucción:

```bash
IFS=';' read -ra datos <<< "$linea"
```

| Parte | ¿Qué significa? |
| --- | --- |
| `IFS=';'` | El punto y coma separa los campos de la línea. |
| `read` | Lee los campos. |
| `-r` | Mantiene literalmente las barras invertidas. |
| `-a datos` | Guarda cada campo en el array `datos`. |
| `<<< "$linea"` | Envía el contenido de `linea` a `read`. |

El array tiene posiciones que empiezan en **0**:

```bash
instruccion="${datos[0]}"
ruta="${datos[1]}"
```

**Ejemplo adaptado a nuestra forma de trabajar:**

```bash
totalLineas=$(wc -l < "$BASE/BashFile.txt")
for ((i=1; i<=$totalLineas; i++));do
    linea=$(sed -n "$i"'p' "$BASE/BashFile.txt")
    IFS=';' read -ra datos <<< "$linea"
    instruccion="${datos[0]}"
    ruta="${datos[1]}"

    if [[ $instruccion == "MKDIR" ]];then
        mkdir -p "$ruta"
    elif [[ $instruccion == "TOUCH" ]];then
        touch "$ruta"
    fi
done
```

!!! note "Por qué usamos `cd`"
    Al comenzar el programa, después de definir `BASE`, ejecutamos `cd "$BASE"`, para que las rutas relativas del fichero se interpreten desde `/workspace/ud1`. La ubicación del script, por sí sola, no cambia el directorio actual.

## 6. Recorrer el fichero

Utiliza un bucle `for` que recorra las líneas desde la primera hasta `totalLineas`.

En cada vuelta del bucle:

1. Obtén con `sed` la línea correspondiente del fichero.
2. Guarda esa línea en una variable llamada `linea`.
3. Separa los campos utilizando `;` como delimitador.
4. Guarda los campos resultantes en un array llamado `datos`.

Una línea como:

```text
MKDIR;./pruebas/ud1_7/scripts
```

debe producir:

```text
datos[0] = MKDIR
datos[1] = ./pruebas/ud1_7/scripts
```

Después guarda esos valores en las variables:

```text
instruccion
ruta
```

## 7. Interpretar cada instrucción

Utiliza una estructura `if` / `elif`.

Si la instrucción es:

```text
MKDIR
```

debes crear la ruta indicada mediante:

```bash
mkdir -p
```

Si la instrucción es:

```text
TOUCH
```

debes crear el fichero correspondiente mediante:

```bash
touch
```

Antes de ejecutar cada acción, muestra en pantalla la instrucción que se está procesando y su ruta.

La salida será similar a:

```text
MKDIR ./pruebas/ud1_7/scripts
TOUCH ./pruebas/ud1_7/scripts/copia.sh
TOUCH ./pruebas/ud1_7/scripts/usuarios.sh
...
```

## 8. Comprobar el resultado

Al finalizar el bucle, muestra la estructura generada utilizando:

```bash
tree /workspace/ud1/pruebas/ud1_7
```

Comprueba que coincide con la estructura solicitada al principio del ejercicio.

Después elimina la carpeta de pruebas:

```bash
rm -rf /workspace/ud1/pruebas/ud1_7
```

y vuelve a ejecutar el script para comprobar que puede reconstruirla completamente a partir de `BashFile.txt`.

## Condiciones

- Debes utilizar **Bash**.
- El script principal será `/workspace/ud1/ud1_7.sh`.
- Las instrucciones estarán almacenadas en `/workspace/ud1/BashFile.txt`.
- Debes utilizar `wc -l` para obtener el número de líneas.
- Debes utilizar un bucle `for` para recorrer el fichero.
- Debes utilizar `sed` para recuperar una línea concreta en cada vuelta del bucle.
- Debes utilizar `IFS` y `read -ra` para separar cada línea y almacenarla en un array.
- Debes acceder a las posiciones `datos[0]` y `datos[1]`.
- Debes utilizar `if` / `elif` para interpretar `MKDIR` y `TOUCH`.
- Para los directorios utiliza `mkdir -p`.
- No utilices `eval` ni ejecutes directamente el contenido completo de una línea de `BashFile.txt`.
- Todo lo generado debe quedar dentro de `/workspace/ud1/pruebas/ud1_7`.

## Ampliación opcional

Cuando la versión básica funcione, añade una tercera instrucción:

```text
COPY;ORIGEN;DESTINO
```

Por ejemplo:

```text
COPY;./BashFile.txt;./pruebas/ud1_7/datos/instrucciones.txt
```

En este caso el array tendrá tres posiciones:

```text
datos[0] = COPY
datos[1] = ./BashFile.txt
datos[2] = ./pruebas/ud1_7/datos/instrucciones.txt
```

El script deberá utilizar `cp` para realizar la operación.
