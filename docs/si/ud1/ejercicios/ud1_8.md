# UD1.8 · Gestión automatizada de archivos y directorios

En UD1.7 leíamos **dos campos** (`INSTRUCCION;RUTA`). Ahora leeremos **tres campos**: `OPERACION;ORIGEN;DESTINO`. El objetivo es automatizar copias y movimientos sin repetir comandos a mano.

!!! info "Entorno de trabajo"
    Utiliza el terminal integrado de VS Code. El script será `/workspace/ud1/ud1_8.sh` y trabajarás **solo** dentro de `/workspace/ud1/pruebas/ud1_8/`.

## 1. Preparación

Crea el fichero `/workspace/ud1/pruebas/ud1_8/instrucciones.txt` y prepara esta estructura **a mano**, antes de ejecutar el script:

```text
pruebas/ud1_8/
├── instrucciones.txt
├── origen/
│   ├── documentos/
│   │   ├── manual.txt
│   │   └── notas.txt
│   ├── imagenes/
│   │   └── logo.png
│   └── config/
│       └── ajustes.txt
└── destino/
    ├── copias/
    ├── imagenes/
    └── antiguos/
```

Los ficheros de texto pueden contener contenido inventado; el PNG puede ser una imagen cualquiera. No emplees aquí datos personales.

## 2. Instrucciones de tres campos

Introduce estas líneas **en este orden** en `instrucciones.txt`:

```text
COPY;./pruebas/ud1_8/origen/documentos/manual.txt;./pruebas/ud1_8/destino/copias/manual.txt
MOVE;./pruebas/ud1_8/origen/documentos/notas.txt;./pruebas/ud1_8/destino/antiguos/notas.txt
COPY;./pruebas/ud1_8/origen/imagenes/logo.png;./pruebas/ud1_8/destino/imagenes/logo.png
COPYDIR;./pruebas/ud1_8/origen/config;./pruebas/ud1_8/destino/copias/config
```

| Operación | Comando | Resultado |
| --- | --- | --- |
| `COPY` | `cp` | Copia un archivo, manteniendo el original. |
| `MOVE` | `mv` | Mueve un archivo; deja de estar en su ruta anterior. |
| `COPYDIR` | `cp -r` | Copia un directorio y su contenido. |

**No borres** las carpetas de pruebas: hay que poder comparar el antes y el después.

## 3. Leer las instrucciones como en los ejercicios anteriores

Al empezar el script define `BASE` y cambia a ese directorio:

```bash
BASE="$(dirname "$0")"
cd "$BASE"
```

Cuenta las líneas con `wc -l` y usa un `for` numérico. Obtén cada línea con `sed`, exactamente como lo vienes haciendo:

```bash
totalLineas=$(wc -l < ./pruebas/ud1_8/instrucciones.txt)

for ((i=1; i<=$totalLineas; i++));do
    contenido=$(sed -n "$i"'p' ./pruebas/ud1_8/instrucciones.txt)
    IFS=';' read -ra datos <<< "$contenido"

    operacion="${datos[0]}"
    origen="${datos[1]}"
    destino="${datos[2]}"

    echo "$operacion $origen $destino"
done
```

!!! tip "Tres valores"
    `${datos[0]}` representa la operación; `${datos[1]}` el origen y `${datos[2]}` el destino. En Bash, las posiciones del array empiezan en cero. Para acceder a cada valor usa siempre `${datos[0]}`, no `$datos[0]`.

## 4. Función `procesarInstrucciones`

Crea una función llamada `procesarInstrucciones` que recorra el fichero y utilice **`if [[ ... ]]`, `elif [[ ... ]]` y `fi`** para decidir qué acción ejecutar.

- Si aparece `COPY`, utiliza `cp` con origen y destino.
- Si aparece `MOVE`, utiliza `mv` con origen y destino.
- Si aparece `COPYDIR`, utiliza `cp -r` con origen y destino.
- Si aparece una operación no contemplada, muestra un aviso y continúa.

Puedes comenzar con esta estructura, completando las operaciones que faltan:

```bash
if [[ $operacion == "COPY" ]];then
    cp "$origen" "$destino"
elif [[ $operacion == "MOVE" ]];then
    echo "Completa esta operación"
elif [[ $operacion == "COPYDIR" ]];then
    echo "Completa esta operación"
else
    echo "Operación no reconocida: $operacion"
fi
```

!!! warning "Rutas y seguridad"
    Los comandos `cp` y `mv` pueden sobrescribir destinos existentes. Trabaja únicamente con las rutas del ejercicio y comprueba el resultado con `tree`. El ejercicio no debe ejecutar instrucciones proporcionadas por terceros ni aceptar rutas fuera de su zona de pruebas.

## 5. Incorporar `find` sin convertirlo en el protagonista

`find` localiza archivos y directorios. Practica primero estos ejemplos:

```bash
find ./pruebas/ud1_8 -type f -name "*.txt"
find ./pruebas/ud1_8 -type d -name "copias"
```

| Parte | Significado |
| --- | --- |
| `find ./pruebas/ud1_8` | Busca dentro de esa carpeta y sus subcarpetas. |
| `-type f` | Solo archivos. |
| `-type d` | Solo directorios. |
| `-name "*.txt"` | Nombres que terminan en `.txt`. |

En el menú añade la opción **2. Buscar archivos**: pide al usuario un nombre o patrón y utiliza `find` para mostrar las coincidencias. Ejemplo de consulta: `*.txt`.

## 6. Menú del programa

```text

```

Utiliza `while [[ true ]];do`, `read` y `if [[ ... ]]` como en UD1.4. La opción 3 utilizará `tree ./pruebas/ud1_8`.

## 7. Comprobaciones de la entrega

1. `manual.txt` aparece en origen y destino.
2. `notas.txt` se ha movido a `destino/antiguos`.
3. `logo.png` está copiado en `destino/imagenes`.
4. `config` está copiado con su contenido.
5. La búsqueda `*.txt` muestra archivos de las subcarpetas.
6. El menú permite repetir la búsqueda y salir.

!!! note "Repetir el ejercicio"
    Si repites la opción de procesar las mismas instrucciones, `MOVE` puede fallar porque el origen ya no estará. Para probar de nuevo, restaura antes los archivos originales de las pruebas.
