# UD3.4 · Servidor web y redirección de puertos con OpenWrt

**Módulo:** Sistemas Informáticos · 1.º DAM  
**Modalidad:** Individual · GNS3  
**Herramientas:** OpenWrt, LuCI, MikroTik RouterOS, Webterm y Python  
**Resultado de aprendizaje:** RA5 · Criterios: a), d), e), f) y g)

## Objetivo

Publicar un **servidor web de nuestra LAN** a través de la **WAN de OpenWrt**, utilizando una redirección de puertos configurada desde LuCI.

## 1. Preparar el proyecto

Crea el proyecto `UD3_4_PUERTOS_damXX` a partir de la UD3.3. Conserva OpenWrt, MikroTik y los ordenadores.

Añade un **segundo Webterm** para hacer las pruebas desde fuera de la LAN y un **switch Ethernet básico** en la parte exterior:

~~~text
            NAT de GNS3
                 |
           Switch exterior
            /          \
    OpenWrt (WAN)    Webterm-WAN
          |
    OpenWrt (LAN)
          |
       MikroTik
       /     \
  Webterm-LAN  PC1, PC2, PC3
  (servidor)
~~~

- **Webterm-LAN** estará conectado a MikroTik y alojará el servidor web.
- **Webterm-WAN** estará conectado al switch exterior y tendrá una IP de la misma red que la WAN de OpenWrt.
- El switch exterior solo sirve para conectar la WAN de OpenWrt, el nodo NAT y Webterm-WAN. **No lo conectes a la LAN**.

Mantén la IP WAN de OpenWrt que ya tienes configurada.

## 2. Poner en marcha el servidor web

Desde las **propiedades del nodo Webterm-LAN → Network**, configura una dirección **estática** fuera del rango DHCP de OpenWrt:

| Parámetro | Valor |
| --- | --- |
| Dirección IP | `10.XX.1.20` |
| Máscara | `255.255.255.0` |
| Puerta de enlace | `10.XX.1.1` |

Recuerda sustituir `XX` por el número de tu usuario. Para `dam70`, el servidor tendrá la IP `10.70.1.20`.

Arranca Webterm-LAN y abre su terminal. Crea una página y arranca un servidor HTTP sencillo:

~~~bash
mkdir -p /root/web
echo "<h1>Servidor de damXX</h1>" > /root/web/index.html
cd /root/web
python3 -m http.server 8000 --bind 0.0.0.0
~~~

Personaliza el texto con tu usuario. **Deja la terminal abierta:** el servidor funciona mientras el comando está ejecutándose.

!!! note "Si no está instalado Python"
    Compruébalo con `python3 --version`. Si no está disponible, instálalo con `apt update && apt install -y python3` desde el propio Webterm, con acceso a Internet.

Desde Firefox de Webterm-LAN, comprueba que abre:

`http://10.XX.1.20:8000`

## 3. Intentar acceder desde la WAN

Configura **Webterm-WAN en DHCP** desde las propiedades de su nodo. Comprueba que recibe una IP de la red exterior.

En LuCI de OpenWrt, consulta la **IP que tiene la interfaz WAN**.

Desde Firefox de **Webterm-WAN**, intenta acceder a:

`http://IP_WAN_DE_OPENWRT:8080`

**Todavía no debe aparecer la página**, porque no hemos creado ninguna regla de redirección.

## 4. Redirigir un puerto desde LuCI

Desde Firefox de Webterm-LAN, entra en LuCI:

**Network → Firewall → Port Forwards → Add**

Crea esta regla:

| Parámetro | Valor |
| --- | --- |
| Nombre | `UD3_4_WEB_damXX` |
| Protocolo | TCP |
| Zona de origen | wan |
| Puerto externo | `8080` |
| Zona de destino | lan |
| IP interna | `10.XX.1.20` |
| Puerto interno | `8000` |

Guarda y aplica los cambios.

Vuelve a **Webterm-WAN** y abre:

`http://IP_WAN_DE_OPENWRT:8080`

Ahora **debe aparecer la página web** alojada en Webterm-LAN.

!!! tip "Qué está ocurriendo"
    El cliente exterior se conecta al **puerto 8080 de OpenWrt**. El router redirige esa conexión al **puerto 8000 de Webterm-LAN**, donde está funcionando Python. La IP WAN es la de OpenWrt, **no la IP del servidor**.

## 5. Preguntas en el README

En GNS3, abre **Edit project → Readme** e indica tu **nombre, primer apellido, usuario y red utilizada**. Responde brevemente:

1. ¿Por qué no podíamos abrir la página desde Webterm-WAN antes de crear la regla?
2. ¿A qué IP y puerto se conecta el navegador de Webterm-WAN?
3. ¿A qué IP y puerto envía OpenWrt esa conexión?
4. ¿Qué ocurriría si detuviéramos el servidor Python sin quitar la redirección?

## 6. Entrega

Comprueba que la página funciona desde la LAN y desde la WAN, que la regla aparece en LuCI y que el README está completo.

Guarda los VPCS con `save`, conserva las configuraciones, detén los dispositivos y utiliza **Export portable project** para entregar:

`UD3_4_PUERTOS_damXX.gns3project`

**No es necesario entregar PDF ni capturas.** Si al importar el proyecto el servidor Python no está en ejecución, habrá que arrancarlo de nuevo.
