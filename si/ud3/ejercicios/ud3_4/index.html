    UD3.4 · Servidor web y redirección de puertos con MikroTik¶

    Módulo: Sistemas Informáticos · 1.º DAM
    Modalidad: Individual · GNS3
    Herramientas: MikroTik CHR, WinBox, Webterm y Python
    Resultado de aprendizaje: RA5 · Criterios: a), d), e), f) y g)

    Objetivo¶

    Publicar un servidor web de nuestra LAN a través de la WAN de MikroTik Router, utilizando una redirección de puertos configurada desde WinBox.

    1. Preparar el proyecto¶

    Crea el proyecto UD3_4_PUERTOS_damXX a partir de la UD3.3. Conserva los dos MikroTik (router y switch), WinBox y los ordenadores.

    Añade un segundo Webterm para hacer las pruebas desde fuera de la LAN y un switch Ethernet básico en la parte exterior:

                NAT de GNS3
                 |
           Switch exterior
            /          \
    MikroTik Router (WAN)    Webterm-WAN
          |
    MikroTik Router (LAN)
          |
    MikroTik Switch
       /     \
  Webterm-LAN  PC1, PC2, PC3, WinBox
  (servidor)
    • Webterm-LAN estará conectado al MikroTik Switch y alojará el servidor web.
    • Webterm-WAN estará conectado al switch exterior y tendrá una IP de la misma red que la WAN de MikroTik Router.
    • El switch exterior solo sirve para conectar la WAN de MikroTik Router, el nodo NAT y Webterm-WAN. No lo conectes a la LAN.

    Mantén la IP WAN de tu router. Consulta la tabla de la UD3 y utiliza como puerto externo el primero de tu rango asignado (por ejemplo, dam70 utiliza 20000). En esta práctica llamaremos a ese puerto PUERTO_EXTERNO.

    2. Poner en marcha el servidor web¶

    Mantén WinBox en DHCP. En esta práctica, Webterm-LAN será un servidor y es la excepción: necesita una IP fija para que la redirección siempre apunte al mismo equipo.

    Detén Webterm-LAN. Desde sus propiedades → Network → eth0 → IPv4 configuration, cambia Addressing mode a Static y configura una dirección fuera del rango DHCP:

    Parámetro Valor
    Dirección IP 10.XX.1.20
    Máscara 255.255.255.0
    Puerta de enlace 10.XX.1.1
    DNS nameservers 192.168.122.1

    Pulsa Apply network configuration y después Apply.

    Recuerda sustituir XX por el número de tu usuario (120 para damx). Para dam70, el servidor tendrá la IP 10.70.1.20.

    Arranca Webterm-LAN y abre su terminal. Crea una página y arranca un servidor HTTP sencillo:

    mkdir -p /root/web
echo "<h1>Servidor de damXX</h1>" > /root/web/index.html
cd /root/web
python3 -m http.server 8000 --bind 0.0.0.0

    Personaliza el texto con tu usuario. Deja la terminal abierta: el servidor funciona mientras el comando está ejecutándose.

    Si no está instalado Python

    Compruébalo con python3 --version. Si no está disponible, instálalo con apt update && apt install -y python3 desde el propio Webterm, con acceso a Internet.

    Desde Firefox de Webterm-LAN, comprueba que abre:

    http://10.XX.1.20:8000

    3. Intentar acceder desde la WAN¶

    Configura Webterm-WAN en DHCP desde sus propiedades Network → eth0 → IPv4 configuration → Addressing mode → DHCP. Pulsa Apply network configuration y después Apply. Consulta la configuración DHCP de la UD3.2. Comprueba con ip addr que recibe una IP de la red exterior 192.168.122.0/24 distinta de la WAN de tu router y de las IP reservadas a otros alumnos.

    En WinBox del router, consulta IP → Addresses y localiza la IP de ether1 (WAN).

    Desde Firefox de Webterm-WAN, intenta acceder a:

    http://IP_WAN_DEL_ROUTER:PUERTO_EXTERNO

    Todavía no debe aparecer la página, porque no hemos creado ninguna regla de redirección.

    4. Redirigir un puerto desde WinBox¶

    Desde el nodo WinBox, conecta al MikroTik que actúa como router.

    Abre IP → Firewall → NAT y pulsa +.

    En la pestaña General, configura:

    Parámetro Valor
    Chain dstnat
    Protocol tcp
    In. Interface ether1
    Dst. Address IP WAN fija de tu router
    Dst. Port Primer puerto de tu rango asignado

    En la pestaña Action, configura:

    Parámetro Valor
    Action dst-nat
    To Addresses 10.XX.1.20
    To Ports 8000

    Guarda con Apply → OK. Si existe un filtro de reenvío que bloquea la conexión, revisa IP → Firewall → Filter Rules y permite únicamente la conexión redirigida hacia el servidor TCP 8000 antes de la regla de descarte.

    Vuelve a Webterm-WAN y abre:

    http://IP_WAN_DEL_ROUTER:PUERTO_EXTERNO

    Ahora debe aparecer la página web alojada en Webterm-LAN.

    Qué está ocurriendo

    El cliente exterior se conecta al puerto externo asignado de MikroTik Router. El router redirige esa conexión al puerto 8000 de Webterm-LAN, donde está funcionando Python. La IP WAN es la de MikroTik Router, no la IP del servidor.

    5. Preguntas en el README¶

    En GNS3, abre Edit project → Readme e indica tu nombre, primer apellido, usuario y red utilizada. Responde brevemente:

    1. ¿Por qué no podíamos abrir la página desde Webterm-WAN antes de crear la regla?
    2. ¿A qué IP y puerto se conecta el navegador de Webterm-WAN?
    3. ¿A qué IP y puerto envía MikroTik Router esa conexión?
    4. ¿Qué ocurriría si detuviéramos el servidor Python sin quitar la redirección?

    6. Entrega¶

    Comprueba que la página funciona desde la LAN y desde la WAN, que la regla aparece en WinBox y que el README está completo.

    Guarda los VPCS con save, conserva las configuraciones, detén los dispositivos y utiliza Export portable project para entregar:

    UD3_4_PUERTOS_damXX.gns3project

    No es necesario entregar PDF ni capturas. Si al importar el proyecto el servidor Python no está en ejecución, habrá que arrancarlo de nuevo.
