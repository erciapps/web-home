    UD1.3 · Rutas absolutas y relativas¶

    Antes de empezar, comprueba que tienes realizada la estructura de directorios del UD1.2.

    Entorno de trabajo

    Trabaja desde el terminal integrado de VS Code. El script principal estará en /workspace/ud1 y las estructuras que genere el ejercicio quedarán dentro de /workspace/ud1/pruebas.

    Preparación¶

    Debes tener, como mínimo, esta estructura creada por el ejercicio anterior:

    /workspace/ud1/
├── ud1_2.sh
├── ud1_3.sh
├── scripts/
└── pruebas/
    └── ud1_2/
        └── APLI/
            ├── WORD/
            │   ├── TEXTO/
            │   └── NOTAS/
            ├── ACCESS/
            ├── EXCEL/
            │   ├── TABLAS/
            │   └── INFO/
            ├── PROG/
            │   ├── JAVA/
            │   └── PYTHON/
            └── VARIOS/
                └── CSHARP/

    Si no existe esta estructura, vuelve al UD1.2 antes de continuar.

    Enunciado¶

    Crea el siguiente script:

    /workspace/ud1/ud1_3.sh

    El script debe utilizar una función llamada e00 y mostrar un pequeño menú desde el que se pueda ejecutar el ejercicio o salir.

    Menú principal¶

    Al iniciar el script:

    1. Limpia la pantalla y muestra un encabezado sencillo.
    2. Pregunta al usuario si desea ejecutar el método e00 (s/n).
    3. Si introduce s o S, ejecuta e00.
    4. Si introduce una opción distinta de s/S o n/N, muestra un aviso, realiza una pausa y vuelve al menú principal.
    5. Si introduce n o N, pregunta si realmente desea salir.
    6. n/N: vuelve al menú principal.
    7. s/S: muestra un mensaje de despedida y finaliza.
    8. cualquier otra opción: avisa del error y vuelve a preguntar.

    Función e00¶

    La función debe realizar las siguientes operaciones en este orden.

    1. Crear un fichero utilizando una ruta absoluta¶

    Desplázate al directorio raíz /.

    Desde allí crea el fichero:

    /workspace/ud1/pruebas/ud1_2/APLI/PROG/JAVA/ud1_3.txt

    Debes hacerlo utilizando una ruta absoluta.

    2. Escribir utilizando una ruta relativa¶

    Desplázate hasta:

    /workspace/ud1/pruebas/ud1_2/APLI/WORD/TEXTO

    Desde ese directorio escribe en ud1_3.txt una frase de tu elección utilizando una ruta relativa para llegar hasta el fichero.

    3. Crear la zona de trabajo de UD1.3¶

    Sin cambiar de directorio, crea mediante una ruta relativa:

    /workspace/ud1/pruebas/ud1_3

    Importante

    En este apartado no debes escribir /workspace/ud1/pruebas/ud1_3 directamente en el comando. Debes calcular la ruta relativa desde el directorio TEXTO en el que te encuentras.

    4. Copiar el fichero¶

    Desplázate hasta el directorio NOTAS utilizando una ruta relativa.

    Desde allí copia ud1_3.txt en:

    /workspace/ud1/pruebas/ud1_3/ud1_3cp.txt

    La copia debe realizarse utilizando rutas absolutas.

    5. Guardar el resultado¶

    Genera el fichero:

    /workspace/ud1/pruebas/ud1_3R.txt

    Debe contener los árboles de estas dos rutas:

    /workspace/ud1/pruebas/ud1_2
/workspace/ud1/pruebas/ud1_3

    Antes de cada tree, escribe una línea que identifique claramente qué estructura se va a mostrar. Por ejemplo:

    Estructura de /workspace/ud1/pruebas/ud1_2

    Al terminar, muestra un mensaje indicando que todas las operaciones se han realizado correctamente y vuelve al menú principal.

    Resultado esperado¶

    Al finalizar correctamente, la parte relevante de tu zona de trabajo será similar a esta:

    /workspace/ud1/
├── ud1_2.sh
├── ud1_3.sh
├── scripts/
└── pruebas/
    ├── ud1_2/
    │   └── APLI/
    │       ├── WORD/
    │       │   ├── TEXTO/
    │       │   └── NOTAS/
    │       └── PROG/
    │           └── JAVA/
    │               └── ud1_3.txt
    ├── ud1_3/
    │   └── ud1_3cp.txt
    └── ud1_3R.txt

    Comprobación¶

    Antes de dar el ejercicio por terminado, comprueba que:

    • el menú acepta mayúsculas y minúsculas;
    • las opciones incorrectas no finalizan el script;
    • se pide confirmación antes de salir;
    • e00 realiza las operaciones en el orden indicado;
    • has utilizado rutas absolutas o relativas exactamente donde se pide;
    • ud1_3R.txt contiene los dos árboles correctamente identificados;
    • no has creado ficheros del ejercicio fuera de /workspace/ud1.

    Sincroniza el ejercicio con tu repositorio¶

    Cuando hayas terminado y comprobado el funcionamiento, sincroniza el trabajo con tu repositorio.

    cd /workspace
git status
git add ud1/
git commit -m "Completar ejercicio UD1.3"
git pull
git push

    Antes de subirlo

    Revisa git status y asegúrate de que solo estás incluyendo los archivos que corresponden al ejercicio.
