    UT1.6 · Cuestionario con Bash y sed¶

    En este ejercicio vas a desarrollar un cuestionario desde terminal. Las preguntas, respuestas y soluciones se almacenarán en ficheros de texto y el script deberá obtener la información necesaria directamente de esos archivos.

    Entorno de trabajo

    Todo el ejercicio se desarrolla desde el terminal integrado de VS Code y dentro de /workspace/ud1. No utilices otras rutas del sistema.

    1. Organización del ejercicio¶

    Crea el script principal:

    /workspace/ud1/ut1_6.sh

    Los datos del cuestionario se guardarán en:

    /workspace/ud1/pruebas/ut1_6/

    La estructura será similar a esta:

    /workspace/ud1/
├── ut1_6.sh
└── pruebas/
    └── ut1_6/
        ├── programacion/
        │   ├── preguntas.txt
        │   ├── respuestas.txt
        │   └── soluciones.txt
        ├── bases_datos/
        │   ├── preguntas.txt
        │   ├── respuestas.txt
        │   └── soluciones.txt
        └── sistemas/
            ├── preguntas.txt
            ├── respuestas.txt
            └── soluciones.txt

    Los nombres de las asignaturas son orientativos. Puedes utilizar otros, pero debes disponer de al menos tres cuestionarios para comprobar que el programa funciona con distintos directorios.

    2. Preparar los cuestionarios¶

    En cada directorio de asignatura crea estos tres archivos respetando exactamente sus nombres:

    preguntas.txt
respuestas.txt
soluciones.txt

    Cada cuestionario tendrá como mínimo 5 preguntas.

    preguntas.txt¶

    Escribe una pregunta por línea. Para cinco preguntas, el archivo tendrá cinco líneas.

    respuestas.txt¶

    Escribe cuatro respuestas posibles para cada pregunta. Cada respuesta debe comenzar por a., b., c. o d..

    Para cinco preguntas, el archivo tendrá veinte líneas:

    a. Primera respuesta de la pregunta 1
b. Segunda respuesta de la pregunta 1
c. Tercera respuesta de la pregunta 1
d. Cuarta respuesta de la pregunta 1
a. Primera respuesta de la pregunta 2
...

    soluciones.txt¶

    Escribe únicamente la letra de la respuesta correcta, una por línea:

    a
d
b
c
a

    El número de líneas de preguntas.txt y soluciones.txt debe coincidir. respuestas.txt debe contener cuatro líneas por cada pregunta.

    3. Inicio del programa¶

    Al ejecutar ut1_6.sh:

    1. Limpia la pantalla y muestra un encabezado de bienvenida.
    2. Pide el nombre del usuario.
    3. Muestra un saludo personalizado.
    4. Limpia la pantalla y muestra el menú principal.

    El menú debe incluir, como mínimo:

    =============================
       CUESTIONARIO
Usuario: Manolito
=============================
1. Jugar
2. Ver resultados
3. Salir

Selecciona una opción:

    El menú debe permanecer en ejecución hasta que se seleccione la opción Salir.

    4. Opción Jugar¶

    Al entrar en esta opción, muestra numerados los cuestionarios disponibles dentro de:

    /workspace/ud1/pruebas/ut1_6/

    Por ejemplo:

    1. programacion
2. bases_datos
3. sistemas

    Pide al usuario que seleccione uno de ellos.

    Una vez elegido, comienza el cuestionario.

    Mostrar cada pregunta¶

    Para cada pregunta debes mostrar:

    • nombre del usuario;
    • número de pregunta actual;
    • número total de preguntas;
    • texto de la pregunta;
    • las cuatro respuestas correspondientes.

    El número total de preguntas debe obtenerse del archivo. No escribas 5 directamente en el código.

    Ejemplo:

    Usuario: Manolito
Pregunta: 1/5

El bus de direcciones:

a. Sirve para localizar una posición de memoria RAM concreta.
b. Es un conjunto de pistas eléctricas paralelas entre sí.
c. Es bidireccional.
d. a. y b. son correctas.

Elige una opción (a, b, c, d):

    Utiliza sed para obtener del fichero la pregunta, sus cuatro respuestas y la solución correspondiente.

    Si el usuario introduce una opción distinta de a, b, c o d, vuelve a pedir la respuesta de esa pregunta sin avanzar a la siguiente.

    Resultado de la partida¶

    Al terminar, muestra el número de aciertos y fallos.

    El mensaje final dependerá del resultado:

    Si acierta todas: USUARIO, muy bien jugado.
Si falla al menos una: USUARIO, puedes mejorar.
Si falla todas: USUARIO, no has dado ni una.

    Sustituye USUARIO por el nombre introducido al iniciar el programa.

    Por ejemplo:

    Resumen de resultados de Manolito:

FALLOS: 2
ACIERTOS: 3

Manolito, puedes mejorar.

Pulsa una tecla para volver al menú...

    5. Guardar resultados¶

    Al finalizar cada partida, añade una línea a:

    /workspace/ud1/pruebas/ut1_6/resultados.txt

    Debe guardarse:

    • fecha;
    • nombre del usuario;
    • cuestionario elegido;
    • número de aciertos;
    • número de fallos.

    Puedes obtener la fecha actual con:

    fecha_actual=$(date +"%Y-%m-%d")

    El archivo puede quedar, por ejemplo:

    2026-09-29 Manolito - sistemas - ACIERTOS: 3 / FALLOS: 2
2026-09-29 Laura - programacion - ACIERTOS: 5 / FALLOS: 0

    6. Opción Ver resultados¶

    Esta opción debe mostrar el contenido almacenado en resultados.txt con un encabezado similar a:

    LISTADO DE PARTIDAS

2026-09-29 Manolito - sistemas - ACIERTOS: 3 / FALLOS: 2
2026-09-29 Laura - programacion - ACIERTOS: 5 / FALLOS: 0

    Si todavía no se ha jugado ninguna partida, muestra un mensaje indicándolo y vuelve al menú principal.

    7. Opción Salir¶

    Antes de finalizar, pregunta al usuario si realmente desea salir.

    Si confirma, limpia la pantalla, muestra un mensaje de despedida personalizado y termina el script. Si cancela, vuelve al menú principal.

    Condiciones¶

    • Utiliza Bash para desarrollar el ejercicio.
    • Utiliza sed para recuperar preguntas, respuestas y soluciones de los ficheros.
    • El número total de preguntas debe calcularse a partir del fichero y no quedar fijado en el código.
    • Cada pregunta debe mostrar exactamente las cuatro respuestas que le corresponden.
    • El programa debe comprobar las respuestas introducidas antes de avanzar.
    • Los resultados de cada partida deben conservarse en resultados.txt.
    • El menú principal debe repetirse hasta seleccionar Salir.
    • Todo el ejercicio debe permanecer dentro de /workspace/ud1.

    Las modificaciones y mejoras sobre el ejercicio son válidas siempre que se mantenga el funcionamiento básico solicitado.
