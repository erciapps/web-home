    UD2.6 · Programación de tareas con Cron y Flask¶

    Módulo: Sistemas Informáticos · 1.º DAM
    Modalidad: Individual · Debian GNU/Linux
    Herramientas: Bash, Cron, crontab, Python, Flask y python-crontab

    Aprenderás a programar tareas que se ejecutan automáticamente, primero desde la terminal de Debian y después desde una aplicación Flask.

    Entorno de trabajo

    Trabaja dentro de /workspace/ud2/cron/ en tu Debian de prácticas. No necesitas ejecutar Flask con sudo.

    Instalar Cron¶

    En Debian, instala Cron desde la terminal:

    sudo apt install cron

    1. ¿Qué es Cron?¶

    Cron es un servicio de Linux que ejecuta comandos o scripts automáticamente en los momentos que indiquemos. Puede servir para hacer copias de seguridad, borrar archivos temporales o registrar información.

    Crontab es la tabla de tareas programadas de un usuario. Las tareas se ejecutan con los permisos de ese usuario.

    Comando ¿Para qué sirve?
    crontab -e Editar nuestras tareas programadas
    crontab -l Ver nuestras tareas programadas
    crontab -r Eliminar todas nuestras tareas

    No borres todas tus tareas

    No utilizaremos crontab -r. Para quitar una programación manual, abre crontab -e y elimina únicamente la línea de esa tarea.

    2. ¿Cómo se programa una tarea?¶

    Cada línea de crontab contiene cinco campos de tiempo y el comando que queremos ejecutar:

    * * * * * /ruta/absoluta/script.sh
│ │ │ │ │
│ │ │ │ └─ Día de la semana (0-7; domingo: 0 o 7)
│ │ │ └─── Mes (1-12)
│ │ └───── Día del mes (1-31)
│ └─────── Hora (0-23)
└───────── Minuto (0-59)

    El símbolo * significa cualquier valor. Con */5 indicamos cada cinco unidades en el campo correspondiente.

    Programación Significado
    * * * * * Cada minuto
    */2 * * * * Cada dos minutos
    */5 * * * * Cada cinco minutos
    0 * * * * Cada hora, en el minuto cero
    0 8 * * * Todos los días a las 08:00
    30 16 * * 1-5 De lunes a viernes a las 16:30
    0 0 * * 0 Los domingos a medianoche

    Por ejemplo:

    */5 * * * * /workspace/ud2/cron/scripts/registro.sh

    Este script se ejecutará cada cinco minutos. En Cron utilizaremos rutas absolutas.

    3. Crear un script que registre la fecha¶

    Vamos a crear un script que escriba la fecha y la hora cada vez que se ejecute.

    Prepara las carpetas:

    mkdir -p /workspace/ud2/cron/scripts
mkdir -p /workspace/ud2/cron/templates
mkdir -p /workspace/ud2/cron/static/css
cd /workspace/ud2/cron

    Crea scripts/registro.sh:

    #!/bin/bash

echo "Tarea ejecutada: $(date)" >> /workspace/ud2/cron/ejecuciones.log

    >> añade texto al final de un archivo sin borrar lo anterior.

    Ejecuta el script manualmente para comprobar que escribe el registro:

    chmod +x scripts/registro.sh
./scripts/registro.sh
cat ejecuciones.log

    Rutas

    Los ejemplos parten de /workspace/ud2/cron/. Si trabajas en otra ubicación, usa pwd para conocerla y adapta las rutas absolutas.

    4. Programar la tarea manualmente¶

    Abre el editor de tareas del usuario:

    crontab -e

    Añade esta línea:

    * * * * * /workspace/ud2/cron/scripts/registro.sh

    Guarda el archivo. Ahora el script se ejecutará cada minuto.

    Visualiza la programación:

    crontab -l

    Consulta las ejecuciones:

    cat ejecuciones.log

    También puedes observar las nuevas líneas con:

    tail -f ejecuciones.log

    Tareas:

    1. Programar registro.sh para que se ejecute cada minuto.
    2. Consultar el archivo ejecuciones.log y observar varias ejecuciones.
    3. Cambiar la programación para que se ejecute cada dos minutos.
    4. Mostrar el resultado con crontab -l.
    5. Eliminar solo esa línea mediante crontab -e.

    5. Administrar crontab desde Python¶

    También podemos crear, consultar y eliminar tareas con Python. Utilizaremos python-crontab, que administra el crontab real del usuario.

    Instala la biblioteca en tu entorno virtual:

    pip install flask python-crontab

    Aunque el paquete se llama python-crontab, lo importamos así:

    from crontab import CronTab

    Crear una tarea¶

    from crontab import CronTab

cron = CronTab(user=True)

tarea = cron.new(
    command="/workspace/ud2/cron/scripts/registro.sh",
    comment="UD2-REGISTRO"
)

tarea.setall("*/2 * * * *")

cron.write()
    Instrucción Función
    CronTab(user=True) Acceder al crontab del usuario
    cron.new() Crear una tarea nueva
    command Indicar qué se ejecutará
    comment Poner un identificador a la tarea
    tarea.setall() Indicar la frecuencia
    cron.write() Guardar los cambios

    Importante: el ejemplo crea una tarea nueva. Si se ejecuta varias veces, podría duplicarla. En el ejercicio de Flask tendrás que evitarlo.

    Mostrar tareas¶

    from crontab import CronTab

cron = CronTab(user=True)

for tarea in cron:
    print(tarea)

    Eliminar nuestra tarea¶

    from crontab import CronTab

cron = CronTab(user=True)

cron.remove_all(comment="UD2-REGISTRO")

cron.write()

    El identificador UD2-REGISTRO permite buscar o eliminar nuestras tareas, sin borrar otras programaciones del usuario.

    6. Ejercicio: gestor de tareas con Flask¶

    Crea una pequeña aplicación web que permita programar, consultar y eliminar una tarea Cron.

    Estructura del proyecto¶

    cron/
├── app.py
├── scripts/
│   └── registro.sh
├── templates/
│   └── index.html
├── static/
│   └── css/
│       └── style.css
└── ejecuciones.log       (se genera al ejecutar)

    Interfaz HTML¶

    Crea una página con:

    • Un desplegable con las frecuencias cada minuto, cada dos minutos y cada cinco minutos.
    • Tres botones: Programar, Consultar y Eliminar.
    • Una zona para mostrar los mensajes de respuesta.

    Utiliza un tema oscuro y un CSS independiente. Puedes reutilizar el diseño de la UD2.5.

    El formulario enviará mediante POST dos valores:

    Campo Valores permitidos
    accion programar, consultar, eliminar
    frecuencia 1, 2, 5

    Endpoints de Flask¶

    Endpoint Método Función
    / GET Mostrar el formulario
    /cron POST Realizar la operación indicada

    Conceptos de Python necesarios¶

    Recibir los valores enviados por el formulario:

    accion = request.form["accion"]
frecuencia = request.form["frecuencia"]

    Acceder al crontab del usuario:

    cron = CronTab(user=True)

    Crear una tarea:

    tarea = cron.new(
    command="/workspace/ud2/cron/scripts/registro.sh",
    comment="UD2-REGISTRO"
)

tarea.setall("*/2 * * * *")

cron.write()

    Eliminar la tarea:

    cron.remove_all(comment="UD2-REGISTRO")
cron.write()

    ¿Qué debe hacer la aplicación?¶

    Programar: crear la tarea con la frecuencia seleccionada. Si ya existe, cambiar su programación sin crear duplicados.

    Consultar: indicar si nuestra tarea está programada y mostrar su frecuencia.

    Eliminar: borrar nuestra tarea si existe e informar del resultado.

    Validar la acción y la frecuencia recibidas. La página debe mostrar el resultado de cada operación.

    No se proporciona el endpoint resuelto: debes completar su funcionamiento.

    Seguridad

    Administra solo la tarea identificada como UD2-REGISTRO. No permitas introducir comandos arbitrarios desde el navegador ni ejecutes Flask como administrador.

    7. Pruebas y entrega¶

    Comprueba desde Flask y desde la terminal:

    1. Programar registro.sh cada minuto.
    2. Consultar la tarea con crontab -l.
    3. Observar las ejecuciones en ejecuciones.log.
    4. Cambiar su frecuencia a cinco minutos sin duplicarla.
    5. Consultar su programación desde la web.
    6. Eliminar la tarea desde Flask y verificarlo con crontab -l.

    Entrega: app.py, scripts/registro.sh, templates/index.html, static/css/style.css y un README.md breve. No subas entornos virtuales ni archivos temporales.

    Diferencia entre detener y desprogramar

    Eliminar una línea de crontab evita próximas ejecuciones, pero no detiene necesariamente un script que ya se esté ejecutando.
